Drop structure files here

CIF, SHELX .res and .ins, POSCAR, XYZ and FHI-aims geometry.in, or a zip file of these. Each file is expanded by its symmetry and sorted into frameworks, networks and whole molecules. Layered metal halides also get the 2D perovskite descriptors. Load several to compare them in one table. Powder XRD shows the simulated pattern of each structure. Drop a measured pattern (.xy) to compare it.

Planes
Make a plane, then measure against it: the distance of an atom from the plane, or the angle between a bond and the plane. Crysta gives the angle between each two planes.

Export

All three save what is shown: the packing block, with hidden atoms left out. The mol2 file keeps every polyhedron centre, also those set to 0 %. The SVG is a vector drawing in which every atom, bond and face is a separate object to edit; it is drawn without perspective, and objects that pass through each other are approximated. The mol2 file carries the cell; its atom types are guessed from the number of neighbours and every bond is written as single.

Polyhedra

Around
Corners
Within Å
Any element can be the centre and any elements the corners. Inside a polyhedron the centre atom and its bonds are drawn faded. Press a row to change that (100 % is solid, 0 % leaves them out) or its colour, opacity and edges; the cross removes it. Polyhedra you add are drawn next to the others, so one element can be the centre of several sets. They change the picture only, not the coordination numbers in the data cards.

Packing

Limits are in cell fractions along each axis. Molecules are kept whole and placed by their centroid.

Directions and planes

Chromophores and transition dipoles

A chromophore is a plane through atoms you pick on one molecule, plus an in-plane reference axis. It is copied to every symmetry-equivalent molecule. Arrows are double-headed because the sign of a transition dipole is arbitrary.
